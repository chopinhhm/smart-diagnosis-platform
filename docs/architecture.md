# 智慧问诊平台 - 架构设计文档

## 整体架构

基于 Spring Cloud Alibaba 微服务架构，采用服务拆分设计：

- **Gateway 网关**：统一入口，路由转发、限流、鉴权
- **Auth 认证服务**：JWT Token 签发与校验
- **Diagnosis 问诊服务**：核心业务，包含 AI 问诊、RAG 检索、记忆管理

## AI 问诊流程

```
用户输入 → 敏感词过滤 → RAG知识检索 → 构建Prompt(双记忆+知识) → AI生成 → SSE流式输出
```

## 双记忆体系

| 记忆类型 | 存储位置 | 作用 |
|---------|---------|------|
| 对话记忆 | Redis List | 维护多轮对话原始文本，防止上下文丢失 |
| 业务记忆 | Redis String | 结构化业务状态（已问症状、科室方向等） |

## 三级缓存架构

```
请求 → L1本地缓存(Caffeine) → L2 Redis缓存 → L3 Milvus向量库
```

缓存命中率优化目标：向量库请求量下降 60%+
